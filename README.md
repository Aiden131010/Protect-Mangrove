# 🌳 红树林守护者模拟器 (Mangrove Guardian Simulator)

一个面向青少年的交互式红树林生态科普游戏。通过 5 个关卡的策略决策，理解
**「排污 → 富营养化 → 团水虱暴发 → 红树退化」** 这条生态因果链。

## 🎮 玩法特色

- **5 大关卡**：从渔村养殖湾到国家公园授牌日，章节式故事叙事
- **决策卡牌**：18 张卡池，每轮抽 3 张 + 2 次换牌，4 组变体做法（集约化 vs 生态化）
- **因果链科普**：每次决策自动弹出大知识卡；社区宣传卡附带可学习的科普海报
- **随机事件**：14 类事件 + 幸运事件，经济压力与危机响应机制
- **沉浸演出**：健康值下降时树会摇晃、倒下；水质变化时海水渐渐变色
- **成就 & 商店**：10+ 成就、金币商店、12 款带专属特效的皮肤
- **多账号存档**：3 个账号 + 访客模式，localStorage 独立隔离
